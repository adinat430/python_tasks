# python_tasks
Выполнены 2 задачи на Python: разбор заказов из чата с очисткой текста, сохранение в JSON и MySQL и расчёт расхода компонентов; пересчёт цен из USD в тенге по курсу Нацбанка РК с округлением до 10 тг, резервным сохранением курса и записью результатов в MySQL. Использовала ИИ (Gemini).
