Тестовое задание на Python

В репозитории находятся решения двух задач:

task1.py — разбор текстовых заказов из чата в JSON с очисткой данных и приведением названий компонентов к единому виду, сохранение заказов и позиций в MySQL, расчёт общего расхода каждого компонента.

task2.py — получение актуального курса USD к KZT с сайта Нацбанка РК, пересчёт цен товаров в тенге с округлением до 10 тенге, сохранение последнего курса в локальный резервный файл на случай недоступности сайта и запись результатов в MySQL.

Требования для запуска:
Python 3.11 или выше
MySQL 8

Установка библиотек:
pip install -r requirements.txt

Настройка и запуск:
Перед запуском укажите свои данные для подключения к базе MySQL (пользователь, пароль, хост) в настройках подключения внутри файлов task1.py и task2.py.

Запуск первой задачи:
python task1.py

Запуск второй задачи:
python task2.py

Использование ИИ:
При выполнении задания использовались ИИ-ассистенты (Gemini и ChatGPT) для помощи в написании и отладке кода.
